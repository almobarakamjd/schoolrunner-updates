# تحديثات سبوي ماث

هذا المستودع **عام** ويحتوي فقط على ملفات توزيع التحديثات (`version.json` وملف الـAPK) للعبة "سبوي ماث". الكود المصدري الفعلي بمستودع خاص منفصل (`schoolrunner`) ولا علاقة له بهذا المستودع.

## كيف يعمل

- `version.json`: يحتوي رقم آخر إصدار متاح ورابط تحميل الـAPK. التطبيق يتحقق من هذا الملف عند فتح الإعدادات.
- `app-release.apk`: ملف التثبيت الفعلي لآخر إصدار.

## نشر إصدار جديد

1. ابنِ نسخة الإصدار: `flutter build apk --release`
2. انسخ الملف الناتج (`build/app/outputs/flutter-apk/app-release.apk`) هنا باسم `app-release.apk` (استبدال الملف القديم).
3. حدّث `version.json`: ارفع رقم `version`/`build` ليطابق `pubspec.yaml` بالمشروع الأصلي.
4. ادفع (push) التغييرين معاً.
